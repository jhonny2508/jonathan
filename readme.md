Projeto APS - Algoritmos de Ordenação

Esse projeto foi desenvolvido como parte da disciplina APS do curso de Ciência da Computação.
O objetivo é implementar, comparar e analisar algoritmos de ordenação utilizando dados reais de desmatamento da Amazônia.

Algoritmos implementados:

Bubble Sort;
Insertion Sort;
Merge Sort;
Quick Sort.

Funcionalidades:

Benchmark de tempo e memória;
Comparação gráfica de desempenho;
Entrada de dados reais.
